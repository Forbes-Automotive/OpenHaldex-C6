Long Learn

Automates the manual add/remove-a-block loop. Turns every frame block for this generation on, then (Gen5 0CQ/VAQ) steps the Launch PWM Floor until the learn is smooth — it may jump on first engage (e.g. to 30%) but must then climb cleanly to 100%. It then removes each additional block one at a time: any block whose removal affects the learn goes back on (flagged if it was actually better without); one that makes no difference stays off. A final confirmation learn is stored against the resulting set. Allow 10–20 minutes with the car running and Haldex CAN active. Cancelling restores the previous blocks, floor and learn table.

Off = the original edited set is kept as-is and only the transferred/additional blocks are bisected. On = every block is tested (longer, and can leave the Haldex with no lock command during a sweep).

Lock Calibration (Nm) 220 Nm

BPK ceiling the spoof frame claims at full command. Not a strength dial — run a Learn and nudge until commanded lock matches delivered (Sent vs Returned on the 1:1 line). Only active with Fix Hunting on.

Launch PWM Floor (%) 0 %

Experimental. Raises the ESP_14 minimum clutch PWM while lock is commanded, for a firmer launch. 0% = off. Collapses off-throttle/FWD/coasting and is clamped below the commanded max.

Controller Options

On a full 50:50 request, demands maximum clutch duty by giving the Haldex no room to modulate. Maximum clamping force, but the Returned % will read lower (bench: ~99% pump duty and ~10.5 A, reporting in the 80s, versus ~56% duty reporting ~98% with this off) — the Haldex backs its own estimate off once the pressure relief valve opens. Increases pump load and current draw considerably. Off by default.

Polls the Haldex ECU for live data using whatever generation is set (Gen5 = UDS; Gen2/4 = KWP2000/TP2.0). Requires Haldex CAN healthy.

Note: Occupies the diagnostic channel — leave OFF when using VCDS or other diagnostic tools.

After 5 min idle with no WiFi clients and both CAN buses silent, sleep until a CAN frame arrives. The first wake frame may be lost.

Additionally parks the CAN transceivers in standby while sleeping, drops CPU freq. to 10MHz, and lowers WiFi AP TX power. Bus activity wakes the transceivers via GPIO interrupt within microseconds; a 2s safety-net probe runs as backup.

Keeps the WiFi up indefinitely while bench testing over USB with no harness connected, overriding CAN sleep above. Self-clears the moment real CAN traffic is seen on either bus (i.e. once actually harnessed to a car), so it is safe to leave on — but turn it off once you're done tuning a permanent install.

Frame Editing (Advanced)

Enable or disable editing of individual CAN frames in normal (non-standalone) mode. Unchecking a frame leaves the car's original frame untouched (clean passthrough). Use this to bisect which edited frame upsets the learn procedure. Changes apply immediately and are saved. Only affects the selected Haldex generation.

Not available for this generation.

WiFi Name (SSID)

Change the access-point name broadcast by the controller. 1–32 printable ASCII characters. Saving restarts the AP — you will need to reconnect.

--

WiFi Password

Set a WPA2 password (min. 8 characters) to secure the access point. Leave blank to keep an open network. Long-pressing the mode button always resets back to open.

--

Home WiFi (Bridge Mode)

Optional: also join a home or garage WiFi network as a client. The controller's own access point keeps running either way — this just makes it reachable (and lets you run backups) from a phone or laptop already on that network, without switching WiFi. Leave blank to disable. The controller still sleeps after 5 minutes without CAN traffic unless Bench Mode is on, and it only looks for the home network for 20 s after starting, then once every 5 minutes, so it can't disturb the AP while you're away from home.

--

Backup & Restore

Export the Expert tune, steering scale, frame edits, settings and WiFi name to a JSON file. Do this before a firmware update — an update can wipe on-device settings. Import brings everything back in one go. WiFi passwords are never written to the file; you'll be asked to re-enter them once after importing if any were set.
